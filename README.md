# Dojix and Greenwick for Windows and Linux

**Work in progress.** One codebase that builds two free, open-source trading journals:

- **Dojix** for forex traders (MetaTrader 4/5, cTrader, TradingView, OANDA and more)
- **Greenwick** for stock and day traders (Thinkorswim, Interactive Brokers, Webull, Schwab and more)

They are the Windows and Linux versions of the Mac apps
[Dojix](https://github.com/djctwo/dojix) and [Greenwick](https://github.com/djctwo/greenwick),
with the same screens and the same numbers. The journal stays encrypted on your computer:
no account, no telemetry.

Nothing is ready to download yet. Releases will appear on this repository's Releases page.
